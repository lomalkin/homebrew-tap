# Homebrew tap for blessh

[blessh](https://github.com/lomalkin/blessh): SSH over Bluetooth Low
Energy, with no pairing and no network.

```
brew install lomalkin/tap/blessh
```

The formula is generated and committed here by the blessh release
workflow; its template lives in the blessh repository
(`packaging/homebrew/blessh.rb.in`). Change it there, not here.
